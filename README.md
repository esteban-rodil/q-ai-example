# Password Generator & Strength Checker

A simple web-based application that generates secure passwords and evaluates password strength with real-time feedback.

## Features

- **Password Strength Checker**: Real-time password validation with visual strength indicators
- **Password Generator**: Customizable password generation with multiple character sets
- **Copy to Clipboard**: Easy copying of generated passwords
- **Responsive Design**: Works on desktop and mobile devices

## How to Use

### Password Strength Checker
1. Enter any password in the text field
2. Click "Check Strength" or type to see real-time feedback
3. View strength rating (Weak/Medium/Strong) with improvement suggestions

### Password Generator
1. Select desired character types using checkboxes:
   - Uppercase letters (A-Z)
   - Lowercase letters (a-z)
   - Numbers (0-9)
   - Symbols (!@#$%^&*)

2. Adjust password length using the slider (4-30 characters)
3. Click "Generate Password" to create a new password
4. Click "Copy" to copy the generated password to clipboard

## Getting Started

1. Clone or download the project files
2. Open `index.html` in any web browser
3. No installation or dependencies required

## Password Strength Criteria

The strength checker evaluates passwords based on:
- Length (minimum 6 characters recommended)
- Character variety (uppercase, lowercase, numbers, symbols)
- Avoidance of common patterns and repetitive characters
